# Data Science Website

A responsive educational website introducing **Data Science** and its core areas.

## Sections
- **Data Science:** A short introduction and overview.
- **Data Analysis:** Explore, clean, and interpret data to discover insights.
- **Machine Learning:** Learn how models find patterns and make predictions.
- **Data Visualization:** Communicate insights using charts and visual representations.
- **Workflow:** A simple overview of the typical data science process.

## Built With
- HTML5
- CSS3
- Responsive layout

## How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in your browser.


## Publish with GitHub Pages
1. Upload `index.html` and this `README.md` to the root of your repository.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site and use the provided site URL.


## Search Engine Indexing
After publishing, add the website URL to Google Search Console, verify ownership if required, use **URL Inspection** to check the page, and choose **Request Indexing**. Indexing is not guaranteed and may take time.


## Project Purpose
This website is created as a learning project to practice building and publishing a basic HTML website and submitting it for Google indexing.
